## How to merge the XML files locally

If you want to combine all three XML files into a single master list for your FRITZ!Box, you can use the provided Python script:

1. Download the `merge.py` script and place it in the same directory as the `.xml` files.
2. Open your terminal or command prompt in that directory.
3. Run the script using the following command:
   ```bash
   python merge.py
   ```
4. A new file named `Merged_Blocklist_FRITZBox.xml` will be created, which you can import directly into your FRITZ!Box.
